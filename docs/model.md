# Класова модель PharmacyStock — варіант 19

## Сутності та інваріанти

| Сутність | Роль | Незмінність | Інваріант |
|---|---|---|---|
| PrescriptionLine | Позиція рецепта | sealed record, get без set/init | MedicineCode не порожній; Quantity > 0; UnitPrice >= 0 |
| Patient | Довідник пацієнтів | sealed record, get без set/init | Id > 0; Name не порожнє; Email містить @ |
| Prescription | Документ зі станом | Змінний агрегат | Id > 0; PatientId > 0; позиції додають тільки в New |
| Medicine | Довідник препаратів | Ціна й код незмінні; запас змінюють методи | Code і Name не порожні; Price > 0; Stock >= 0 |
| ArchivedPrescription | Архівний перегляд | Незмінний знімок доступних даних | ArchivedAt >= CreatedAt; немає операцій зміни позицій і стану |

## Переходи станів рецепта

| Звідки | Куди | Метод | Умова |
|---|---|---|---|
| New | Approved | Approve | Є хоча б одна позиція |
| New | Cancelled | Cancel | Завжди |
| Approved | Dispensed | Dispense | Попередній стан Approved |
| Approved | Cancelled | Cancel | Відпуск ще не виконано |
| New, Approved | Expired | Expire | Команда зовнішнього сценарію, відпуск не виконано |
| Dispensed, Cancelled, Expired | — | — | Термінальні стани |

## Припущення

Approved означає підтверджений рецепт, Dispensed — відпущені препарати.
Робота не моделює клінічне призначення ліків або нормативний строк дії рецепта.
Expire є явною командою зовнішнього сценарію; поточний годинник у модель не вбудовано.
Email перевіряється мінімально: непорожнє значення та наявність @.
Ціну позиції фіксують у момент створення; пізніша зміна довідника її не змінює.
RegularPricingPolicy не дає знижки, DiscountPricingPolicy приймає частку від 0 до 0.5,
VipPricingPolicy дає 10 %. Кожна позиція округлюється до 2 знаків (ToEven).
Після підсумку зберігається загальне правило з Legacy: якщо сума > 1000, віднімається 50.
Це навчальні правила ціноутворення, а не твердження про реальну аптеку.
TotalOf обчислює оцінку вартості; статус рецепта не змінює ціну позицій.
Сховище в пам'яті не дозволяє повторні Id; GetAll повертає окремий список значень.
Lines є справжнім read-only переглядом; привести його до змінюваного List не можна.
Архів фіксує стан і копію списку на момент створення; подальша зміна оригіналу його не змінює.
Сповіщення у демонстрації пишеться в переданий TextWriter, реальних листів немає.
Базові типи Documents і розрахунок ЛР3 збережено окремо; 35 попередніх тестів лишаються.
