## Три власні рішення

1. Приватні static поля лишаються з _, хоча обидва джерела іменування використовують s_. У наявному PharmacyStock це дозволяє не створювати масовий шум перейменувань без зміни поведінки. Статичність перевіряють у декларації; ціну втрати короткої підказки прийнято в ADR-001.

2. Нові тести мають Method_Situation_Result, хоча загальна конвенція методів в обох джерелах — PascalCase без такого поділу сценарію. Три частини імені дозволяють прочитати причину червоного xUnit-тесту без відкриття файла. Ціна — локальний виняток CA1707 лише для *Tests.cs; production-методи не отримують цього винятку. Старі зрозумілі імена не перейменовують лише задля форми, щоб зберегти історію покриття.

3. Для метрик визначено числові пороги рев’ю та для грошей вузький предметний контракт. Обидві загальні сторінки не встановлюють таких аптечних меж, тому це свідоме доповнення, а не цитата з них. Без чисел різні рецензенти по-різному вирішують, коли розділяти метод; для PharmacyStock ціна такого спору більша за ціну одного короткого виміру. Не називаємо ці ручні критерії автоматичними помилками складання.
