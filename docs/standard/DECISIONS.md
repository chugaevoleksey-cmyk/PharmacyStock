# Журнал рішень

## ADR-001 — Єдиний префікс приватних полів
Дата: 21.11.2026. Статус: прийнято для стандарту 1.0.0. Власник: Чугаєв Олексій Михайлович.

Проблема: чинні production- та тестові поля мають _camelCase, включно зі static readonly. Альтернативи: s_ для static як у dotnet/runtime; this. для розрізнення; єдина _. Рішення: зберегти _. Статичність видно у декларації, а масове перейменування без поведінкової користі утруднить перегляд історії. Негативний наслідок — за коротким використанням не видно static; це перевіряється навігацією редактора. Перевірка: чинні naming symbols окремо від const, IDE1006 та рев’ю N-08. Оцінка переходу на s_: щонайменше пошук усіх static полів та повний формат/тести; міграцію не проводили й не видаємо оцінку за виміряні години.

## ADR-002 — Округлення грошей і точність доз
Дата: 21.11.2026. Статус: прийнято. Власник: Чугаєв Олексій Михайлович.

Проблема: приклад методички використовує AwayFromZero, поточна політика PharmacyStock — ToEven. Альтернативи: негайна заміна, збереження контракту, окрема політика каси. Рішення: D-14 зберігає ToEven, будь-яка зміна точки або режиму округлення потребує нового ADR і тесту на середину. Дозу не округляємо за грошовими правилами; decimal разом із DoseUnit є контрактом майбутнього розширення, а не існуючою функцією Medicine. Наслідок: можна відтворити чинний результат без прихованої регресії; якщо замовник вимагатиме інший касовий алгоритм, потрібна свідома зміна версії та міграційні приклади. Перевірка: тести чинних сум і майбутній окремий тест точності 0.5 mg. Перегляд: до 21.12.2026 у STD-201.
