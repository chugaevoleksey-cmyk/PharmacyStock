# Історія
GitHub мав типовою гілку lab6-refactoring. Робота над СР3 почалася з неї.
Поточний main з результатом ЛР8 приєднано merge-комітом без переписування
історії. Його вихідні файли збережені побайтово в archive/lr8, попередня
робоча версія — в archive/labs. Випуск 1.0 продовжує Prescription,
PrescriptionLine, PrescriptionStatus і DomainRuleException, додає складські
сценарії та замінює демонстраційний запуск консольними командами.
Активні метрики стосуються src/ і tests/; архівні .txt до них не входять.
Дати комітів не підмінялися. Розробка СР3 виконана 21.11.2026; вимога
шести днів саме для СР3 не виконана і позначена «частково» в самооцінці.
