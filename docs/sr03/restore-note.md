# Перевірка відновлення
На GitHub перший прогін виявив старий NuGet.Config з clear без жодного джерела.
Виправлено на офіційний https://api.nuget.org/v3/index.json.
Локальний онлайн-запит у сесії Windows завершився помилкою Schannel
SEC_E_NO_CREDENTIALS. Це не обхід перевірки сертифіката: TLS не послаблювався.
Окремо відновлено порожній пакетний кеш із локальної копії офіційних nupkg
і перевірено build/test. Онлайн-відновлення перевіряє чистий runner GitHub Linux.
Сервісний локальний feed до репозиторію не входить і для користувача не потрібен.
