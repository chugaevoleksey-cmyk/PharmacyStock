# Метрики випуску
Активні src/ і tests/, без bin, obj та archive. Roslyn рахує логічний рядок
як фізичний рядок з токенами, крім порожніх, коментарів і окремих фігурних дужок.
Для методу враховується тіло без сигнатури; конструктори включено.
CC: 1 + if, цикл, catch, case/arm, ?:, &&, ||, ??, ?.; без default-рядка switch.
Depth рахується від 1 для тіла методу. Повтор — однакові шість токенізованих
логічних рядків поспіль, локальні назви не нормалізуються.
Це точний пошук текстових клонів; семантичні повтори перевіряються рев'ю.

Джерела: 508 логічних рядків; тести: 326;
разом 834.
Найдовше тіло: 14; максимум CC 7,
глибина 3, параметрів 4; точних вікон клону: 0.
Відтворення: pwsh tools/metrics.ps1. Результат coverage/metrics-src.json і metrics-tests.json.
Схема правила залежностей додатково перевіряється ArchitectureTests.
