# Спостереження до рефакторингу
Пробний очікуваний результат −1 для звичайного клієнта дав фактичні 760; журнал — 03-observation-failed-probe.txt. Після фіксації поведінки всі тести зелені.
1. uk-UA дає кому в усіх сумах; invariant — крапку. Обидва повні звіти зафіксовано тестами.
2. DescribeClient читає DateTime.Now.Year; очікування залежить від року запуску. Тест не усуває недетермінованість на межі року.
3. Від’ємну ціну прийнято, загальна сума може стати від’ємною. Поведінку залишено.
4. Preview з порожнім списком повертає 60, а Handle — ERR: empty. Це різні початкові контракти.
Кожен тест встановлює культуру й відновлює попередню через IDisposable. Жоден очікуваний результат після цього коміту не змінюється; окремий LegacyCalls містить лише адаптацію викликів при зміні API.
