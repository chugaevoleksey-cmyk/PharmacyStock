# Посібник користувача PharmacyStock 1.0
Програма працює з вигаданими препаратами M001..M060. Парні коди потребують
рецепта, навчальний ліміт — 10 одиниць на один відпуск. Це не медичні правила.
Потрібен .NET SDK 8.0.427. Запуск із кореня: `dotnet run --project src/PharmacyStock.App`.
Після запуску видно вітання та «Дані завантажено». Введіть help.
Ввід — одна команда на рядок; аргументи розділені пробілами, дати yyyy-MM-dd.
Назви з пробілами шукайте одним фрагментом: search name препарат.

## UC-02 Надходження
Введіть `receive 1 M002 20 2026-12-01` (дата має бути сьогодні або пізніше).
Вивід: `Виконано.` Повтор тієї самої партії:
`Номер партії має бути додатним і новим.` Залишок не подвоюється.
Для наступної поставки використайте новий номер.

## UC-03 Рецепт і стан
Введіть `create 19 1 M002 2` → `Виконано.`
Далі `state 19 approve` → `Стан: Approved`.
Номер пацієнта умовний; ім'я, адреса й телефон не вводяться.
`state 19 cancel` скасовує активний рецепт; після цього відпуск заборонено.
`state 19 expire` позначає активний документ простроченим.

## UC-01 Відпуск
Для підтвердженого рецепта: `dispense M002 2 19` → `До сплати: 25.00`.
Повтор `dispense M002 1 19` →
`Операцію відхилено: Відпуск дозволено лише зі стану Approved.`
Запас після першої операції 18, повтор його не змінює.
Для безрецептурного M001 номер рецепта можна не вказувати.
Кількість 0, від'ємна або понад 1000 повертає повідомлення і дозволяє нову команду.
Препарат відпускається з придатних партій із найближчим строком першими.
Частковий відпуск кількості однієї позиції закриває весь рецепт.

## UC-04 Пошук
`search code m002` → `M002|Навчальний препарат 02|12.50`.
`search name препарат` → 60 рядків у порядку M001..M060.
`search code missing` → `Нічого не знайдено.`
Підтримуються лише code і name. Пошук не змінює дані.

## UC-05 Близькі терміни
`expiring 30` показує `код|партія|термін|залишок` і відповідні партії.
Горизонт 0 — тільки сьогодні; 90 — найбільший дозволений.
Прострочені й нульові залишки не включаються; порядок: дата, код, номер.
Без відповідних партій: `Нічого не знайдено.`

## UC-06 Збереження і резервна копія
`save` → `Дані збережено.` `load` → `Дані завантажено.`
Зміни зберігаються лише командою save. Перед exit виконайте save.
Файл — runtime/stock.json; скопіюйте його у власну резервну теку після save.
Журнал — runtime/app.log. Для відновлення закрийте програму, замініть
stock.json резервною копією й запустіть знову. Не редагуйте файл під час роботи.
При пошкодженому JSON команда load не замінює поточний стан;
помилковий файл автоматично не перезаписується. Спершу зробіть його копію.

## Помилки
«Невідомий код препарату» — перевірте код через search.
«Недостатньо придатного запасу» — додайте партію або зменште кількість.
«Рецепт поза строком дії 0..30 днів» — цей документ не підходить для відпуску.
«Перевищено навчальний ліміт одиниць» — кількість більша за каталогове правило.
«Неправильна кількість аргументів» — введіть help і повторіть команду.
«Помилка файла: перевірте шлях, доступ і структуру JSON» — перевірте runtime,
доступ на запис і резервну копію. Програма не виводить вміст файла в журнал.

## Повторювана демонстрація
`dotnet run --project src/PharmacyStock.App -- --demo` виконує надходження,
створення, підтвердження, успішний і повторний відпуск, звіт та save.
Демо щоразу починається з seed у runtime/demo-stock.json і не змінює stock.json.
Фактична дата у звіті демо — поточна дата + 7 днів.
