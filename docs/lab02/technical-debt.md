# Технічний борг

1. Знижка за кількість рядків не враховує кількість одиниць препаратів. Поведінку зберігаємо.
2. Від’ємна кількість і ціна не заборонені. Додавання нової валідації змінить поведінку.
3. Рядки зберігаються як string[]; числа перетворюються через поточну локаль. Типізацію відкладено.
4. Пороги, ПДВ, переходи станів та слово «Товар» успадковано з прикладу; правила аптеки уточнюються окремо.
