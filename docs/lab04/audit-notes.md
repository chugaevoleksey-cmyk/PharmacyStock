# Аудит навчального Legacy-прикладу

Приклад перенесено в Legacy для аналізу й виключено зі складання; його не запускали.
У методичці не наведено реалізації FilePrescriptionStore і SmtpMailer; вони не вигадуються
і не підміняються справжніми файловими чи поштовими адаптерами.
Клас має 6 виділених причин для зміни: ціна, життєвий цикл, JSON-зберігання,
сповіщення, CSV-звіт, архівування. Це явне групування відповідальностей для цього аудиту.
Із семи методів широкого інтерфейсу фактично викликається один — SaveToFile.
Для непорожнього документа Archive завжди доходить до перевизначеного AddLine,
який кидає NotSupportedException; це доказ порушення LSP.
Знімок вихідних файлів зберігається у docs/lab04/legacy та Git.
