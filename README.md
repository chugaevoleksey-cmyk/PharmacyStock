Навчальний консольний облік партій і відпуску препаратів за умовним рецептом.

## 3 Швидкий старт
Відкрийте термінал у **порожній теці**. Встановіть .NET SDK 8.0.427, Git.
Три команди:
```sh
git clone --branch v1.0 https://github.com/chugaevoleksey-cmyk/PharmacyStock.git .
dotnet build -c Release -warnaserror
dotnet run --project src/PharmacyStock.App
```
Для повторюваного прикладу додайте `-- --demo` до третьої команди.
`help` показує синтаксис; `save` зберігає перед `exit`.

## 4 Структура
src/PharmacyStock.Core — домен, правила й прикладні сценарії без файлів/консолі.

src/PharmacyStock.App — команди та композиційний корінь.
tests/PharmacyStock.Tests — xUnit, фіксований годинник, фейкове сховище, JSON-тести.
data/seed.json — 60 умовних препаратів. archive/ — попередні лабораторні як .txt.

## 6 Перевірки і покриття
Локальний еквівалент CI однією командою (PowerShell 7):
`pwsh -NoProfile -File tools/verify.ps1`.
Окремо: `dotnet test -c Release`. Набір: 58 зелених тестів, без пропусків.
Покриття Core: **92,82% рядків (194/209)**, **91,30% гілок (84/92)**.
Межа — домен і прикладний шар, App та Infrastructure виключено явно.
HTML: coverage/index.html; сирі дані: tests/PharmacyStock.Tests/coverage.cobertura.xml.
`pwsh tools/metrics.ps1` відтворює метрики: 834 логічні рядки разом із тестами,
максимум CC 7, тіло методу 14, вкладеність 3. Архів до цих чисел не входить.
[Непокрите](docs/sr03/coverage-gaps.md), [експеримент](docs/test-experiment.md).

## 7 Технології
.NET 8, C# 12, xUnit 2.9.3, coverlet 6.0.2, Roslyn, GitHub Actions.
CI перевіряє формат, Release -warnaserror, тести й поріг рядкового покриття 70%.
Гілка ci-demo навмисно червона й не зливається; main має бути зеленим.
XML Core генерується з CS1591 як помилкою. Ручний стандарт — CODING_STANDARD.md;
для поточного src/ обов'язкові Roslyn Recommended та .editorconfig, старі StyleCop
пакети лишилися лише в архіві й не заявляються як активна перевірка.

## 8 Обмеження і борг
Один рецепт містить одну позицію і закривається після одного відпуску.
Бази даних, конкурентного запису та реальних медичних правил немає.
Збереження — явно командою save; журнал не має резервного каналу при відмові диска.
